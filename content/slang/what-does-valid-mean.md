```markdown
# English: Valid
- **Meaning:** Something that is true, correct, or officially accepted.
- **Slang Explanation:** "On point" or "legit."
- Example: "Is that ID valid?" -> "Is that ID legit?"
# 中文: 有效
- **意思：** 真实的，正确的，或被正式认可的。
- **俚语解释：** "相当准" 或 "靠谱的。"
- 示例： "这证件有效吗？" -> "这证件靠谱吗？"
```
