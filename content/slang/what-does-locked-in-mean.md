```markdown
## English: Locked In
### Chinese: 被锁定了 ( bèi suǒ diàn le )
#### Explanation:
这个短语用来形容一个人或某事被某种决定或局面所固定，无法改变或退出。比如，如果你投资了一家公司并且无法在短期内出售你的股份，你就被认为是“被锁定了”。在这种情况下，你可以说你“被锁定了”，用于表达这个决策让你难以改变当前的状态。
```

```markdown
## English: Locked In
### Chinese: 深陷其中 ( shēn xiàn zhōng qū )
#### Explanation:
这个短语用来形容一个人被某些问题、想法或者境况所深深地束缚或卷入，无法轻易摆脱。例如，如果你正在处理一个非常复杂且艰巨的项目，以至于你想抽身都很难，这时你可以用“深陷其中”来形容你的状态。
```

```markdown
## English: Locked In
### Chinese: 没得选 ( méi dé xuan )
#### Explanation:
这个短语常用来表示某个决策已经确定，你没有选择的余地或无法退出。就像你购买了一件商品，合同上写着你必须在协议期间内支付全额，否则可能会有额外的违约金，这时候你说“没得选”，表示逃脱不了这种局面。
```

```markdown
### Chinese: 离不开了 ( lí bù kāi le )
```
